# 全库摘句与创作分类 v1

2026-10-08。用户明确：全部资料需要分类，创作单位是一两句，可跨作品组合一期。沿用现有本地Python与原生界面，不接收费模型、不增加依赖。

## 范围与取舍

把全库每篇原文切成保持连续出处的片段，保留原文字符起止位置；按主题、意境、观众共鸣切入点及场景意象组织。作者原文、自动初分、助手精读提案、用户采用分别记录。不可把不同作品缝成一条“原诗”。句子在同一期成为各自镜头，仍复用已有版本和归档流程。

比较：仅对整篇贴标签会污染篇内不同情绪，继续关键词筛整篇不能满足用户；全量外部模型分析成本和数据外发未获授权。当前选择本地逐片段规则初分，加助手对典型片段的上下文校正。能覆盖全库，但规则标签不是逐句语义审定；无依据的片段保留“待细分”，绝不为了100%标签覆盖硬造解释。界面明确方法与依据。

开放研究依据（2026-10-08访问）：[CCPD作者仓库](https://github.com/yuting-wei/CCPD)将主题和情绪作为多标签分类；[CCL25古诗词赏析评测](https://aclanthology.org/2025.ccl-2.26/)区分内容理解与情感识别。这里只参考问题拆分，没有导入其数据或模型，未确认许可证的标注不复制。没有查得当前账号受众或足够新的平台一手偏好数据；检索发现的2022历史传播报告不能用来证明2026爆款。因此“治愈休息、孤独共鸣、想念故乡”等为我们的创作切入点，不设流量概率或虚构评分。

产物保存在古诗词选题库“摘句分类/v1”下：片段JSONL、全篇分类CSV、分类覆盖报告、助手精读提案与本轮核验。生成脚本输出派生文件，不覆盖原文、用户分类或制作记录；未来重分另立版本。

## 验收

所有21,615条均有处理结果；所有摘句严格等于原文对应字符区间，组句不跨作品、不跨章节标题。长文按句读切片，短句与过长句保留边界提示。分类有方法与依据，未知单列；否定、想象及比喻不直接变为真实景物。选句页支持主题/意境/共鸣/学段检索与多选加入一期，写入继续经过Store原句验证。用临时数据测试跨作品组期，正式库不写验收作品。

## 本轮验证与交付

最终生成135,918个片段，覆盖全部21,615条来源记录；ID唯一且原文字符区间逐条校验通过。分类定义35个主题、17种意境、22个共鸣方向，另有待细分类。56条收录关系匹配精读提案；45,343段主题和89,908段意境仍待细分，不能声称全库语义分类完成。完整结果见[分类说明](../项目/01-古诗词意境/选题库/摘句分类/v1/README.md)。

运行：`python3 -m unittest discover -s tests -v`，31项，30.958秒，OK；`node --check app/web/app.js`、`node --check app/web/excerpts.js`、`python3 -m py_compile app/excerpts.py app/server.py scripts/build_excerpts.py`均退出0。新测试先因缺少模块、404接口、短片段未合并、未保留独立名句失败，再完成实现通过，未跳过或放宽历史测试。

浏览器在端口8767与独立目录实际勾选《山居秋暝》《鸟鸣涧》两条摘句，加入同一期保存，分别保留作品ID和原句；核对落盘2镜头/2来源。正式端口8765未写入作品，页面已更新为“意境选句”；“空灵宁静＋安静与休息”返回168条。界面[截图](意境选句界面.png)。原文库、14个历史分类草案及正式制作状态保持不变。

代码新增摘句生成与检索模块、只读接口及分页选句页，批量组期复用现有Store保存协议；文档与派生数据都在doc内。初分文件尚为v1草案，没有新SHA-256。没有安装依赖、访问凭据、付费模型调用、资料上传、推送或部署；联网仅公开研究读取。项目仍是未提交工作区，本轮文件范围按以上实际变更记录，不能把未跟踪文件当作相对提交的精确差异。

限制：关键词初分不是语义模型，标签可能遗漏、冲突或误判；片段不全是可独立成片的好句。尚未实现逐片段人工标签编辑，现有“保存分类”仍面向原作品。当前选句篮刷新会清空，加入一期后才保存。首期具体意境、图像风格及生成预算仍由用户选择；分类标签与潜在共鸣均未得到实际观众反馈验证。
