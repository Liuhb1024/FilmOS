# 中式巨物美学短片

第二阶段扩展项目，当前先保留结构和参考。待古诗词意境流程稳定后，将图片、运动、剪辑和归档经验用于真实景观、建筑或器物的超现实尺度改造。

入口：[景观参考库](参考库/README.md)、[专属提示词库](提示词库/README.md)、[专属资产库](资产库/README.md)、[分期制作](分期/README.md)、[协作记录](协作记录.md)。

## 每个场景的设计顺序

1. 选参考：识别地点、机位、主要地貌或建筑特征，以及图片来源和允许用途。
2. 定改造：保留什么、放大什么、增加什么；每一处夸张都作为创作设定标注。
3. 定尺度：设置人物、舟、道路或树木等参照物，统一相互大小、距离和遮挡。
4. 定运动：先让静帧中的空间成立，再决定镜头经过哪里、主体和云雾怎样变化。
5. 定衔接：同一地点的连续镜头保持布局、天气、光源与结构；跨地点意境组镜主要检查风格和节奏，不能把所有镜头都强制当作同一空间。

不把景区官方照片直接当成任意改编或商用素材。参考研究可先记录链接，执行图生图前再确认具体图片用途。优先使用自摄、明确允许相关用途的素材或原创生成参考。

## 起步范围

先选一个地点、一个主要巨物、一个明确空间关系。第一组验证采用固定或简单运动，成功后再尝试复杂绕行与穿越。地点、审美基调、第一期内容和预算均待确定。
