# EP001《云起时》· 横屏脚本 v2

工作标题与表达是助手当前制作提案，用户可随时调整，未视为最终采用。用户已明确授权开始执行一主线程＋一本期制作线程的协作；首轮只生成一张候选，逐镜推进，不批量生成。

表达：走到尽处，仍有天地。雨后入山、看见细节、暂时停步、云起开阔、归于清静。不是将十首诗解释为同一种哲理，也不伪造作者原意；“停下来也能看见另一番天地”是本片创作角度。

横屏16:9，试剪目标约100秒。10组诗句拆成16个剪辑镜头，其中结尾可以复用，因此16镜不等于必须生16张新图。实际时长按朗读与可用素材再调整，不是可灵生成参数。

参考追逐星辰AIGC《半生》的写实影视质感：真实材质、受控光色、空间层次及景别变化；不沿用旧竖屏图的偏壁纸取向。不强行添加人物，不要求每镜都是风景大全景。首轮用S01测试画面质感、横向构图和空间，先不铺开。

## 当前制作任务

第一张：S01，王维《山居秋暝》“空山新雨后，天气晚来秋”。雨后山林的横屏远景，让观众首先进入一个可以停下来的空间。先写并保存完整提示词，再调用内置imagegen一次。不给图加字，字幕后期做；以自然质感、湿石树木细节、克制薄雾、深浅空间和有方向的柔光为重点，不堆巨物、密集楼阁或荧光。准确记录实际有无参考图；如果只有文字研究，就写“文字归纳，未传参考图”，不宣称模型已看过原视频。

图片输出后检查横屏比例、主体结构、光色、意境和后续运动空间，并保存到项目资产库。仅候选，不自动采用；第一张交给用户看，不继续生成其余15镜。图生视频目标是可灵V3，但先不提交视频任务；待采用图片后核对官方模型指南和用户平台参数再交付适配提示词。
