# 《云起时》v4：从诗心到镜头

2026-10-08。用户本轮要求：重新理解诗歌的故事、上下文与作者处境，交付新版16镜及16份Midjourney完整提示词；Codex同步使用另行适配的内置生图输入。此前v2/v3保留，最终采用由用户决定。本轮不提交视频。

## 研究事实与创作边界

七首作品、十组摘句仍组成约100秒的诗意组镜；不是七位作者共同经历的一条传记。以下“心境”是依据全文的解释，不是可考的作者当天心理记录。人物是诗中人的视觉化，服装与动作是创作设计，不宣称历史肖像或精确建筑复原。

|作品|已核对的上下文与背景|本片转译与限制|来源|
|---|---|---|---|
|王维《山居秋暝》|全文由新雨秋晚、松月石泉到浣女渔舟，结尾表达愿留。通常联系辋川山居；没有足以锁定写年的证据。|清明、安顿而有生活声息；不画荒山绝境，不虚构安史之乱后的特定创伤。|[兰州大学全文与赏析](https://jiwei.lzu.edu.cn/meiriyishi/2020/0901/130386.html)；该页赏析转引古诗文网，属于机构承载的后人解释。|
|王维《鹿柴》|《辋川集》中的一首；前文“不见人／但闻人语响”与返照相互映衬。|画外人声、林内一小片夕照；无鹿群，无月光，无顿悟史实。|[南通大学全文与鉴赏](https://sxss.ntu.edu.cn/2018/0301/c6266a165784/page.htm)|
|贾岛《寻隐者不遇》|通行署贾岛，松下童子说师父采药；写年、山名和人物身份本轮未确证，古籍归属亦有异说。|问答与云深的缺席；可以视觉化童子指山，但不画“已找到隐者”。|[识典古籍《说唐诗》](https://www.shidianguji.com/mid-page/7460251397188583434)为古籍解释传统；[人民网通行全文](https://theory.people.com.cn/n/2014/0717/c386828-25294465.html)只取得检索文本，正文读取超时。|
|王维《终南别业》|全文“兴来每独往”到“偶然值林叟，谈笑无还期”。写年有741与758年以后等不同说法；思想解读亦不唯一。|随兴、自在；停步和安坐，水穷不是绝望。两镜不为凑故事增加未经讨论的生平事件。|[光明日报道家解读](https://epaper.gmw.cn/gmrb/html/2024-12/28/nw.D110000gmrb_20241228_2-11.htm)、[古诗文网全文及另一系年说](https://m.gushiwen.cn/shiwenv_cd7027786b98.aspx)|

|陶渊明《饮酒·其五》|从“结庐在人境／心远地自偏”到采菊、见山、归鸟、忘言。归田生活背景可用，具体417年未获得足够核验证据。|平常生活中的不经意与自得；S09/S10/S11/S15/S16维持东篱、低缓南山、夕岚的空间。取消用王维云谷代替陶诗结尾的旧方案。|[北京市园林绿化局全文](https://yllhj.beijing.gov.cn/ztxx/bjhx/hhzs/202010/t20201019_2114482.shtml)、[华东师大出版社教学用书](https://data2.ecnupress.com.cn/files/12875458a416b1/resource/7313535bfb8e64/156506518769309.pdf)|
|刘禹锡《望洞庭》|通行系于824年秋赴和州途中，依据相关行程记载作推断；具体写作站位未确证。|无风秋湖、柔润月色、小巧君山，表达开阔亲切；不虚构岳阳楼站位，不把银盘青螺画成实物，不套用流泪悲秋。|[南通大学全文、行程引文与鉴赏](https://sxss.ntu.edu.cn/2018/0302/c6266a165841/page.htm)|

访问日期均为2026-10-08。原诗正文在本地既有来源库中保留，不改写原文。后人赏析用于支持解释，不等同原作者自述。需要学术定论的确切写年仍待更深入校勘，本片不依赖有争议的年份。

## 两条提示词路线

|路线|已核实能力与适配|本轮选择|
|---|---|---|
|Midjourney V8.2 HD|官方兼容表支持HD、画幅、Stylize、风格参考；16:9 HD预计约2912×1632，实际可能有变化，非原生4K。V8不支持quality参数。|用户自行提交；完整英文画面文本，统一`--ar 16:9 --v 8.2 --hd --s 150`。150是待试起点，不是已验证最优值。设置选择Standard；不默认Raw，以免进一步滑向普通摄影。|
|内置image_gen|工具仅提供prompt、参考图片和透明背景开关，具体模型/quality/size未暴露。官方GPT Image指南提供场景、布局、参考用途与局部修改方法。|单镜中文分项输入；先讲诗意再落实画面，明确主次及自然光学。请求最高可用原生画质和3840×2160，但核对实际输出，不称调用了确定的2.5/Sunburst/max。|
|Midjourney V7高质量路线|V7支持`--q 4`，与V8不是同一兼容合同；更多GPU时间不等于原生4K，且q4与Omni Reference不兼容。|不作为本轮默认，避免混用版本和参数；若用户已有V7风格参考，可另行建立版本。|

选择依据：用户已有Midjourney生成路径，Codex内置路径已获授权；不安装依赖、不接数据库、不上传既有素材到外部平台。MJ文本没有假造sref地址、seed或已采用参考图；用户提供喜欢且可使用的成图后，才可真实添加风格参考。两平台同一镜头保持内容和表达一致，但提示写法分开。没有“照抄MJ句法就能在GPT Image复现风格”的证据。

## 官方方法与证据

- [Midjourney Prompt Basics](https://docs.midjourney.com/hc/en-us/articles/32023408776205-Prompt-Basics)：以清楚的主体、环境、构图、光色和情绪描述目标，避免冗长清单。生平解释保留在镜头卡，画面文本写可见结果。
- [Version](https://docs.midjourney.com/hc/en-us/articles/32199405667853-Version)、[参数列表](https://docs.midjourney.com/hc/en-us/articles/32859204029709-Parameter-List)、[Upscalers](https://docs.midjourney.com/hc/en-us/articles/32804058614669-Upscalers)：核对V8.2、HD写法和16:9预计像素；版本固定以便比较。
- [Stylize](https://docs.midjourney.com/hc/en-us/articles/32196176868109-Stylize)：0–1000，默认100；艺术解释强弱与质量档分开。
- [Raw](https://docs.midjourney.com/hc/en-us/articles/32634113811853-Raw)、[Style Reference](https://docs.midjourney.com/hc/en-us/articles/32180011136653-Style-Reference)：研究员实际查看官方人物闻花与风格权重示例图；Raw偏摄影，风格参考迁移风格而不锁定身份。此为对官方示例的观察，不是本片效果保证。未下载或传入这些示例。
- [Quality](https://docs.midjourney.com/hc/en-us/articles/32176522101773-Quality)：按版本适用，不给V8.2错误添加q4。
- [OpenAI图像提示指南](https://developers.openai.com/api/docs/guides/image-prompting)：历史背景、主体关系、参考图片用途与局部编辑需明确；官方有2.5示例，不代表本地内置工具实际暴露该模型。

沿用此前已实际观察的[《半生》研究](../../../选题库/参考研究/半生-方向对齐.md)与[LibTV／开源案例研究](../../../../../research/古诗词中式美学提示词研究-2026-10-08.md)，本轮不重复上传或套用其素材。既有inkstone、CCLAP只作方法背景，未引入代码、权重或新依赖；不把小项目热度当选型理由。

## 完成条件与审阅

16镜各自具有完整MJ输入、完整GPT输入、诗意依据、静帧事件及相邻镜头关系。实际生图保存每次完整输入与真实参考路径、原件位置、项目输出、像素、可见参数、审阅和未知费用。全部图片为用户待审候选，不能自动填写采用。

先看主形和疏密，再看人物动作与空间，再看自然光学和局部结构。禁止用全图模糊、插值或锐化制造规格达标。逐张review，有问题明确写明；本轮每镜先一张，不以无限抽卡追求稳定承诺。任何追加返修保存新版本。
