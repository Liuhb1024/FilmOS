# 初中：来源、覆盖和已知差异

访问与整理日期：2026-10-08。

当前完成的是**2022年语文课标中7—9年级60个推荐条目的目录和古代原文入库**，不是“全国所有版次初中教材全部收齐”，也不是已经按某套教材逐字校定。原文可用于选题检索；实际制作字幕、朗诵或教学内容之前，仍须核对采用的具体文本版本。

## 文件入口

- [清单.csv](清单.csv)：60个课标条目；29诗、9词、2曲、20文言文。
- [原文.md](原文.md)：按课标序号排列，注明作者／典籍及全文或选段边界。
- [补充原文.md](补充原文.md)：现已确认九年级上册课外诵读的4首补充。
- [补充清单.csv](补充清单.csv)：与课标60条分开计数。
- [富贵不能淫](补充-富贵不能淫.md)：已确认人教2017年7月版八上教材归属的补充，当前修订版归属待核。
- [原始汇编PDF](来源/湖南女子学院-135篇原文汇编.pdf)及[初中提取原始文本](来源/来源提取-初中60篇.txt)：原件保留；PDF实际含高中部分，文件名表示其义教汇编部分，不意味着全文件只有135条。

《论语》十二章按课标计1条，《孟子》三则按课标计1条。因此60条不等于把每一小章都拆开后的文本段数。体裁是项目基础分类，不是课标额外规定的细分体系。没有添加场景、情绪或制作标签。

比较两种现实方案：单独抓“必背大全”速度快，但版本混用严重；以官方课标作为有限清单，再配公开古代原文，更容易检查缺项。本轮选择后者。没有采用随机搜索排名前列的商业题库作为课程范围，也没有把现成汇编标作校定版。

## 已经处理的差异

1. **第43条《孟子》三则**：官方2022课标是“鱼我所欲也；得道多助，失道寡助；天将降大任于是人也”。原汇编错误以“富贵不能淫”替代第二则。工作原文已依据课标改为[得道多助，失道寡助](https://www.gushiwen.cn/shiwenv_294c939b3665.aspx)；“富贵不能淫”另存教材补充，没有删除原始证据。
2. **第46条**：官方2022课标为《吕氏春秋》“伯牙鼓琴……世无足复为鼓琴者”，原汇编写成《列子》“伯牙善鼓琴……吾于何逃声哉”。已改用[《吕氏春秋》选段](https://www.guwendao.net/shiwenv_a00028c4f0be.aspx)，不能混成同一文章。
3. 《使至塞上》“侯骑”按[文本](https://www.gushiwen.cn/shiwenv_eae647c5c110.aspx)改“候骑”；《白雪歌送武判官归京》“不得空”按[文本](https://www.gushiwen.cn/shiwenv_444df93c9bdf.aspx)改“不得控”；《三峡》提取漏字“绝 多生怪柏”按[文本](https://www.gushiwen.cn/gushiwen_76c98b6c01.aspx)补为“绝巘多生怪柏”。
4. 《虽有嘉肴》原汇编仅至“教学相长也”，已依据[公开古代原文](https://m.gushiwen.cn/shiwenv_b85acee19435.aspx)补入《兑命》末句。
5. 原汇编“是（斯）人也”将异文直接混入正文；工作原文按课标目录“是人也”处理，不把括注当正文。保留《论语》各章出处标记，去掉版面页码、断行和“一作”行内提示；异文仍可回原件查。
6. 原汇编的朝代栏有“宋·李煜”“元·宋濂”、崔颢名字后乱码等问题。清单直接使用课标作者／出处，没有沿用这些朝代栏。不能据此称作者生平考据已完成。
7. 《湖心亭看雪》末尾漏右引号，工作文本补齐。对于“拏／拿”“珮／佩”“曾／层”“具／俱”“涂／途”等版本差异，没有强行统一。剩余逐字校定必须按实际采用教材或可靠古籍版本进行。

## 版权与验证边界

只提取古代公版作品正文、作者与题名等事实。高校公开PDF作为本地来源证据保存，不声称整本汇编、版式或第三方现代内容属于开源许可；不复制现代译注进入创作库。本轮没有借用GitHub代码库、模型权重或商业素材，也没有选择软件技术栈，所以不以“热门项目”替代原典与课标。

结构检查：CSV60条、ID连续无重复、Markdown60个对应标题、必填来源字段非空；补充另计。目录三页已直接目视对照，全文已从来源提取并纠正所发现问题，尚无60篇全部对照新版教材逐字校验的证据。没有安装依赖、登录、付费、生成媒体、上传或Git推送；未计算SHA-256。
