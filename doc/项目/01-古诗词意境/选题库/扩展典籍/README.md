# 扩展典籍

2026-10-08。这里是供创作选题检索的开放古典文本，**不属于教材必背目录，也不是逐字校定本**。

## 来源与许可

采用 [chinese-poetry/chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 的古代原文数据；上游版本为 `b8594f81a89752241442f2ce267d6f66f96704ee`。仓库采用 [MIT许可](https://github.com/chinese-poetry/chinese-poetry/blob/b8594f81a89752241442f2ce267d6f66f96704ee/LICENSE)，原许可与署名完整保存在[来源快照/LICENSE](来源快照/LICENSE)。这是数据整理仓库的许可；不把它扩展解释为所有第三方图片、译注和现代作品的通用授权。

本次只导入古代原文、题名及作者；未收现代译文、赏析，未导入 `ci.song.2019y.json` 现代投稿集。公开网络下载约10MB原始JSON；下载操作未发送本地项目资料。上游 [Issues](https://github.com/chinese-poetry/chinese-poetry/issues) 存在缺字、作者错误与异文问题，因此全体扩展记录标为采用前待核。

## 文件与复现

- [扩展篇目.json](扩展篇目.json)：本地可检索派生正文、ID、来源文件与原始序号。
- [典籍关联.json](典籍关联.json)：现有ID与合集关系，不复制成多个分类正文。
- [全库统计.json](全库统计.json)：包含教材层的全库统计快照；现代教材短引文单独计数。
- `来源快照/`：原始下载文本；蒙学目录繁体原件与简体派生结果分开保留。
- [导入脚本](../../../../../scripts/import_classics.py)：`python3 scripts/import_classics.py` 从已保存来源复现派生数据，不联网、不改原件。蒙学繁简转换使用macOS自带Swift/Foundation，脚本依赖本机Swift；已生成库及看板运行不依赖Swift。

去重只按规范化正文，不按同名词牌合并；去除标点和空白后完全相同才关联。异文、节选、组章与跨学段记录仍可能并存。教材新增在典籍导入之后合并，因此不同来源层之间也可能保留重复收录关系。记录数不等于独立全文作品数。

筛选线索由文字匹配生成，有命中原句可查；“月”可能是月份，“鸟”可能出现在否定句里。画面内容、情绪和导演处理在具体创作时再决定，禁止把检索标签写成用户已确认的风格。
