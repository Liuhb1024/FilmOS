# 古诗文创作分类草案 v0.1

日期：2026-10-08。状态：助手试分，待用户讨论；不是已定分类标准或学术定论。本轮从已收文本中选14个样例，检验是否方便选题和寻找画面，不改原文、不新增软件、不生成媒体。

## 与提示词三层结构的关系

“共用方法→项目配方→本镜完整输入”管理创作经验；本文件的分类帮助我们找到想做的内容。两者用途不同，不把课文目录、意境标签和提示词模板强行放进同一棵层级树。

三层结构是当前可行的组织方法，优点是能分清哪些内容复用、哪些内容本次修改；尚无本项目生成结果证明它能提高采用率或降低成本。暂不建立配方组合引擎。实际写提示词时仍要检查冲突、删掉无用词，不能机械拼接模板。

## 先分四个方面

| 方面 | 回答什么 | 起步例子 |
| --- | --- | --- |
| 内容主题 | 这篇主要在讲什么 | 山水自然、日常生活、送别、思乡、羁旅、志向品格、家国历史、人生感怀、学习处世 |
| 场景 | 能从哪里开始构造画面 | 江河、山林、池塘、海岸、田野、道路、庭院、居所、楼台、城关 |
| 意象 | 原文里有哪些具体东西 | 月、舟、雪、雨、荷、桥、树、鸟、琴、灯；可以记录声音和动作 |
| 情绪／气氛 | 我们读到什么感受 | 宁静、孤寂、思念、喜悦、惆怅、壮阔、昂扬、肃穆；允许多种并存 |

每条可以有多个标签，先少量使用；标签清单随样例调整。主题、情绪是对文本的解释，须有语句支持且允许修订。场景与意象优先依据原文；合理推定的场景注明推定，不当成原诗明确交代。

季节、时段、天气作为需要时填写的补充信息，不强迫每篇都有。水墨／写实、青灰／暖金、横屏／竖屏、运镜、人物数量与成本留到策划和配方里决定，不作为诗文固有属性。

## 如何避免越分越乱

- 按编号引用已有原文；一个作品可被多个主题找到，不为“月景”“思乡”“夜晚”各复制一份原文。
- 当前先按篇试分。长诗、文言文出现多场景、多情绪时，后续用“原文编号＋原句起讫”细到片段，保留上下文；不把全篇情绪强加给每一句。
- 原文说到不代表画面必须同时出现。比喻、回忆、想象、否定中的物象要分别说明，例如《江雪》的鸟是“不出现”的鸟，《望庐山瀑布》的银河是比喻。
- 一次审阅主要看：能否找出想要的作品，有没有误读，有没有重复或无用标签。不以标签数量多作为完成标准。

## 需要保留的语义边界

| 作品 | 原文依据 | 对后续画面的约束或讨论点 |
| --- | --- | --- |
| 江雪 | “千山鸟飞绝，万径人踪灭” | 不自动补飞鸟或来往人群；孤舟上仍有人，不能误读为全画面无人。 |
| 静夜思 | “疑是地上霜” | 不直接当作真实霜雪；窗户、床形制属于后续考据和创作选择。 |
| 望庐山瀑布 | “日照”“疑是银河落九天” | 银河不是必须出现的夜空。要做宇宙瀑布，应明确属于幻想改编。 |
| 山居秋暝 | “竹喧归浣女，莲动下渔舟” | 宁静不等于无人物、无声音；不把整首压成空山静帧。 |
| 春夜喜雨 | “随风潜入夜”“晓看红湿处” | 夜景与晓景分开组织；不要求同一张图同时表达所有时段。 |
| 天净沙·秋思 | “小桥流水人家”“断肠人在天涯” | 单独截出温馨村居可能丢失羁旅者的处境，组镜需保留对照。 |
| 石灰吟 | “要留清白在人间” | 清白兼有品格含义，不能只归类成白色石头素材。 |
| 陋室铭 | “无丝竹之乱耳”“可以调素琴” | 无喧闹不代表不可有琴；开篇仙、龙是论说铺垫，不默认真的画仙龙。 |
| 虞美人 | “恰似一江春水向东流” | 可以用江水作视觉转译，但要注明它源于比喻，不是原文交代人物身处江边。 |

## 先检查能不能找东西

1. 找“江河＋孤寂”：应能找到《江雪》，而不会只因为都有水就把《小池》视为同一气氛。
2. 找“月＋思乡”：可找到《静夜思》；《山居秋暝》也有月，但不能自动贴上思乡标签。
3. 找“荷＋清雅”：可联想到《爱莲说》；《小池》的“小荷”更偏清新日常，具体表达另选。
4. 找“壮阔”：可找到《望庐山瀑布》《观沧海》《登高》，还需用惊叹／昂扬／悲凉区分表达。

这只是人工检视样例，不是已建成搜索系统或已验证的生成流程。下一步审阅这些区别是否符合用户的选题习惯，调整后再扩展到其余文本。
