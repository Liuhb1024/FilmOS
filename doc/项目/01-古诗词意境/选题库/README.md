收录清单已按学段、体裁和来源整理。现已开始[创作分类草案 v0.1](创作分类草案-v0.1.md)，先试分14个样例，按主题、场景、意象和情绪检视；尚未为全部作品批量打标签，草案待讨论。

每条记录：作品与作者、原句及上下文、原文出处、教学来源与版本、主题、意象、情绪解读、可拍的画面变化、适合的系列、已用期数。原文与我们的画面联想分开写，未核对的名句不直接进入字幕。

| 首批主题建议 | 可查的意象 | 重点判断 |
| --- | --- | --- |
| 江上送别 | 江面、孤舟、岸边、远帆 | 人物关系和离开过程能否成立 |
| 月下思乡 | 月、窗、庭院、远行者 | 避免把不同诗句的情绪混成同一套画面 |
| 山中独处 | 林、山、溪、空谷 | 用光线、声音和留白组织变化 |
| 边塞与远行 | 城关、风沙、山路、马 | 地理、时代与服装要有依据，避免无关元素堆叠 |

以上是创作标签建议，不是已经核验的教材分类。[官方资料入口及读取范围](../../../research/资料入口与组织方案-2026-10-08.md)记录课程标准与教材来源。
