# 摘句与创作分类 v1

2026-10-08。处理全部21,615条来源记录，形成135,918个连续原文片段。片段可重叠，同一作品可跨学段重复收录，数字不等于独立金句数或已经确认的好句数。全部为分类提案，尚未获得用户逐条确认。

## 怎么使用

看板默认打开“意境选句”。先选内容主题、意境感受、共鸣切入点，勾选不同作品的原句，再点“加入一期作品”。可以新建一期或加入已有一期，按选择顺序成为独立镜头，各自保留出处；之后继续原有的生图、图生视频、版本与素材归档流程。

例如“空灵宁静＋安静与休息”可寻找《山居秋暝》《鸟鸣涧》等不同作品的句子。共鸣切入点是我们的选题建议，例如离家与归属、低谷与自处、日常小美好，没有声称平台用户一定喜欢或已验证热度。每期还需统一风格与情绪走向，勾在一起不等于已经形成好作品。

可展开“更多筛选”选择画面元素、片段用途、学段和分类方法。点击句子看完整原文、附近上下文和分类依据；摘句框可以继续调整，不限于自动切出的范围。选句篮只在当前页面会话临时保留，加入一期后才写入项目；刷新页面会清空未保存的选句篮。

## 分类结构

- 内容主题：35类，如山水行旅、隐逸闲居、思乡怀人、送别重逢、人生哲思、边塞征战；另设2个待细分类。
- 意境感受：17类，如空灵宁静、清冷孤寂、离愁不舍、旷达释然、明丽欣悦、苍凉悲壮；另设意境待细分。
- 共鸣切入点：22类，均为创作提案，不是作者本意或人气评分。
- 画面元素：仅作画面候选，保留否定、比喻、追忆等提示。不能看到“鸟飞绝”就给画面加鸟，不能把“绿蚁”画成蚂蚁。
- 片段用途：意境画面候选60,345；哲理旁白候选1,935；叙事抒情候选41,637；需调整摘句范围32,001。用途来自片段长度与内容线索，尚未经生成验证。

同一片段可以有多个主题、意境及共鸣方向，统计不可简单相加。主题记录讨论的内容，意境记录感受，共鸣记录我们的选题角度，不能互相代替。

## 全量处理与精读的真实边界

本轮已完成全量提取与规则初分，**没有完成全库语义精读分类**。135,918个片段中，56条收录关系匹配助手精读提案，其余135,862条为规则初分。有45,343个片段主题仍待细分，89,908个片段意境仍待细分；没有足够依据时不硬填情绪。带标签的规则结果也不代表已经判断正确。

50个精读提案定义存于[助手精读提案](助手精读提案.json)，覆盖典型语境纠偏；部分作品不在当前库或存在异文，未匹配就不伪造原文。跨学段重复及不同片段边界可能产生多条匹配。已知名句另外提取独立区间，避免被前面短句吞并；这些区间可能与普通切片重叠。

规则只使用本片段，不把整首诗的悲伤或豪迈直接传给每一句。词与古文的自动断句仍可能不完整，短于8汉字、长于45汉字或停在逗号等情况会提示调整；短句可与相邻连续句合并。章节标题不参与摘句，不跨作品拼接。每段保存原文ID、字符起止位置，界面加入一期仍受原句验证。

## 文件、复现与下一轮

- [片段.jsonl](片段.jsonl)：全量逐片段分类和依据，供程序读取。
- [全篇分类.csv](全篇分类.csv)：每条来源记录的主题/意境汇总及片段数。
- [分类覆盖.json](分类覆盖.json)：所有类别的真实覆盖数量。
- [核验.json](核验.json)：全量原句、ID与来源关系校验结果。
- [设计与研究依据](../../../../../看板/摘句分类设计.md)：方案取舍与研究边界。

生成入口：在仓库根目录运行 `python3 scripts/build_excerpts.py`。本轮全部从本地原文生成，无模型API、无付费调用、无数据外发、无新哈希。代码为[app/excerpts.py](../../../../../../app/excerpts.py)与[scripts/build_excerpts.py](../../../../../../scripts/build_excerpts.py)。v1尚为草案；确认或冻结之后，下一轮修改应建立新版本并保留旧版，不覆盖用户采用和历史生成记录。

继续完善应优先精读拟用于首期的候选，再扩大到其他主题。用户对片段的修改由Codex保存为新的精读提案版本；当前看板中的“保存分类”仍是原作品级标签，不冒充独立片段分类编辑器。
