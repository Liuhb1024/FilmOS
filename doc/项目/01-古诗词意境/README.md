# 古诗词意境短片

当前优先推进的项目。先按意境组织诗句与画面，制作多张美图及必要的轻运动片段，配合剪辑、朗读或环境声。整首诗的完整影像化留作后续扩展，教学归属作为辅助信息，不以教材册次作为主要创作导航。

## 内容分类

| 维度 | 怎么用 |
| --- | --- |
| 文本身份 | 作品、作者、原句、上下文、体裁；古文另标，不混称古诗词 |
| 教学来源 | 学段、课程标准版本、教材出版社／版次／册次、推荐或必背的具体依据；不明则待核 |
| 创作主题 | 山水、送别、思乡、边塞、咏物、节令等，可多选 |
| 情绪与意象 | 孤独、旷达、思念等解释，及月、江、舟、山、雨等画面元素 |
| 制作需要 | 人物数量、场景数量、季节、时段、运动与预期难点 |

一首作品只存一份内容；主题、意象等用标签关联，可进入多期。解释与镜头是我们的创作，不写成作者已经说过的话。先保证诗意成立，再追求漂亮画面。

入口：[选题库](选题库/README.md)、[专属提示词库](提示词库/README.md)、[专属资产库](资产库/README.md)、[分期制作](分期/README.md)、[协作记录](协作记录.md)。

当前制作方式见[逐镜制作协作约定](逐镜制作协作约定.md)：横屏，参考《半生》的画面风格；先定表达与段落，再逐张提供提示词、看图迭代。视频目标为用户指定的可灵V3，按采用图片另写视频提示词，由用户提交平台。每轮保留输入与结果，实际复用后再提炼配方。

## 起步范围

按用户 2026-10-08 的决定，先收集小学、初中、高中的古诗词与文言文，按学段、体裁和来源范围整理。当前已扩充到21,615条记录：小学130、初中125、高中101，课外典籍21,259；含2条现代教材目录与短引文。来源分层显示，课标清单覆盖不等于全国所有教材全量覆盖。看板可组合66种文字线索检索；14个人工分类样例保持草案，尚未给全库确定创作意境。

之后选一个意境，核定使用的诗句及上下文，制作一个完整小段。系列可按江上送别、月下思乡、山中独处等组织；同一收录文本通过引用进入不同主题和期数，不复制成多个主题版本。

不默认做人物身份、口型与长剧情连续性；仍检查单期画幅、画风、光色和运动节奏。只需静图推拉的镜头可直接剪辑，真正有表达价值的运动再考虑视频生成。当前《云起时》已确定[V5图片与稿子](分期/001-山水清欢/横屏-v5/V5定稿.md)为本期制作基线，16镜、100秒；停止重新生图，等待用户下一步安排。
