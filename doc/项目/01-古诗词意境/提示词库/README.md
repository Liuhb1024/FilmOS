## 寒江孤舟候选示例

仅用于说明怎样填模板，不是已选第一期，不引用或声称忠实还原某首诗。来源：共用意境生图 v0.1、图生视频 v0.1；模型尚未选择，状态待试。

图片草稿：冬日江面被薄雾覆盖，一叶小舟位于画面下方偏右，与远处山势形成明显的大小对比。前景水面开阔，远山轮廓逐层变淡。阴天柔光，整体低饱和青灰色，舟上保留一处微弱暖色，表达安静而辽阔的感受。画面采用写实摄影质感，主体层次清楚，留出大片江面。画幅按本期方案另定。

视频意图草稿：固定远景，江面细小波纹缓慢扩散，薄雾轻轻横移。孤舟停留在原有位置，岸线和山体形状保持稳定，运动舒缓。实际生成前需提供采用图片，并按目标模型写法调整。

这里的写实、青灰和微暖色仅是示例选择，不是用户已确定的项目风格。可用空江、孤舟、远山等不同画面组织一组意境，但先检查整组节奏，不机械重复同一构图。
