# 王者官方资料索引

这里记录官方材料里的内容及直接出处，不混入我们尚未确认的剧情。已找到的入口及核验范围见[研究记录](../../../research/资料入口与组织方案-2026-10-08.md)。

资料按需要扩展为世界与规则、地区与势力、人物与关系、事件与时间线、器物与能力。每条事实保留来源页面、访问日期、所属游戏或故事系列，以及原文明确说明了什么；没有明确日期的事件只写先后关系，不编出年份。

同一英雄的本体资料、皮肤主题故事、活动故事与衍生作品分别标明来源。遇到冲突先并列保留，写明本小说采用哪一支；不能只按发布时间新就自动覆盖全部旧材料。百科、玩家推断和二创可做寻找线索的入口，不自动视为官方设定。

剧情需要补全的空白移到[本项目设定](../小说/设定与连续性.md)，标为我们的新增。当前尚未整理完整王者世界资料库。
