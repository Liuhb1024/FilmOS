# 小说写作入口

先回答主角想要什么、谁或什么阻碍他、作出选择会失去什么，再扩展背景。世界设定服务冲突和人物，不靠不断补充名词推动故事。

写作时先读[设定与连续性](设定与连续性.md)及所用的官方资料，再形成总纲；正式写作后按 `第一卷/第001章-标题.md` 归档。卷数、章数和字数依故事需要决定，当前不预设长篇规模。

每章先列本章目的、视角人物、冲突推进、转折和结尾状态；正文确定后更新已发生事件、人物知道的信息、关系变化及伏笔。候选大纲和正式正文分别标注，改写不能悄悄抹掉已确定前情。
