# 王者项目资产设定

当前只预留整理入口，没有已生成素材。先从小说实际使用的人物、地点和物件开始，不为全部英雄批量生成。每项用[素材卡](../../../共用/模板/素材卡.md)记录，文件在本目录按类型和名称逐步增加。

| 类型 | 应先明确的内容 |
| --- | --- |
| 人物 | 本小说采用的形象版本、年龄表现、比例、面部、服饰、当前状态与不可变特征 |
| 声音 | 音域、质感、语速、发音、情绪范围、角色声音来源及允许用途 |
| 场景 | 地区、空间布局、出入口、主要尺度、时间天气与可用机位 |
| 武器道具 | 所属人物、尺寸材质、能力边界、握持或使用方式、剧情状态 |
| 服装与效果 | 造型版本、穿戴结构、损伤状态，以及剧情需要的效果限制 |

不是所有素材都需要三视图或多张表情图；根据实际镜头与生成工具需要补充。人物外观、声音与角色小说设定相互引用，但一次视觉试验不自动修改小说人物性格。

项目当前暂存。以后启动时实际文件放在本目录下的人物、场景、声音等按需子目录。用于某个镜头时记录具体版本，不用“最新图片”替代历史引用。
