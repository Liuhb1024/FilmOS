# 共用素材与媒体归档

各项目专属媒体放在该项目的资产库；这里只有确实适合跨项目复用的素材。当前没有媒体，只有归档说明。原先集中在 `doc/assets/` 的方案已调整，不再使用该目录。

素材卡记录来源、允许用途、实际文件、版本、参考职责和生成记录。外部链接不代表文件已取得；临时下载地址不代表永久存档。相同文件只保留一个主要位置，其他项目以相对路径引用。

按实际需要建立参考、图片、视频、声音或单期目录。文件名如 `S001-image-v001.png`、`S001-video-v002.mp4`；引用时包含完整相对路径。已采用文件不覆盖，修改另存版本，未经要求不自动清理失败素材。

根目录 `.gitignore` 排除 `doc/` 下常见媒体和工程大文件，素材卡、提示词及台账仍可由 Git 跟踪。新增文件格式在提交前检查体积与范围，不将凭据或带认证参数的链接写进记录。

GitHub 上的文字不构成媒体备份。真正制作后将各项目资产库及此目录备份到用户指定的另一存储位置，并检查可恢复性；当前没有执行备份。
