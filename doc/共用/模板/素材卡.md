# 素材卡模板

复制到所属项目的参考库或资产目录，一份卡对应一个可以稳定引用的素材／角色设定。未知项写待补，不创建虚假的媒体链接。

- 素材名称与编号：
- 所属项目与类型：人物／场景／建筑／武器道具／服装／声音／风格参考
- 来源性质：自行拍摄／外部参考／官方资料／AI 生成／本项目原创设定
- 来源作者、URL、访问日期与允许用途：
- 本地文件与版本：尚无文件时写未取得
- 用途：身份／结构／构图／色彩／材质／运动／声音；不笼统写参考
- 必须保持的特征：
- 允许变化的特征：
- 已采用的正面、侧面、细节或状态版本：按实际需要填写
- 生成依据或官方事实依据：
- 相关项目、期数或章节：
- 采用状态与用户决定：

人物重点记身份、比例、面部特征、服装和携带物；场景重点记布局、尺度、方向与机位；武器重点记尺寸、材质、握持方式与所属人物。声音重点记音域、音色质感、语速、发音、情绪范围，以及实际有权使用的配音／声音来源，不把某位真人姓名当作克隆许可。
