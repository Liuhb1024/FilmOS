# 参考图改造与局部修正模板

版本 v0.1，状态待试。用于保留已有画面优点，再改天气、材质、尺度或局部错误。工具需要支持相应编辑；写了保留并不保证模型一定保留。

## 可填模板

```text
基于实际提供的【参考图】编辑。
保留【明确可见的构图、轮廓、机位或空间关系】，只调整【本轮主要改动】。
将【目标部分】改为【具体变化】，与原图的【光源、透视、遮挡、材质或反射】协调。
【其他参考图如有】仅用于【指定用途】，不用于替换【应保留内容】。
```

每张参考先说明职责：原景结构、风格、色彩或特定主体。多个互相矛盾的参考不能都写成“严格遵循”。具体文件、用途和允许范围在素材卡记录。

巨物改造补主体与人物、舟、道路等参照物的大小关系，以及前后遮挡。放大什么是创作决定，不冒充真实景点原貌。

失败后先判断指令、参考或原图结构的问题。能够通过裁切、局部编辑或剪辑解决的，不必整张重抽。更换多个条件时如实记录，不能把改善都归功于一个词。

模板为本项目自行整理。[来源与适配边界](../../research/意境短片开源方法与共用库-2026-10-08.md)。尚无本项目成功率数据。
