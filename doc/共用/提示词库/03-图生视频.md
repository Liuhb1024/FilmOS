# 意境图生视频模板

版本 v0.1，状态待试。让已选图片发生一段清楚的变化；图片通常提供外观、构图与光色依据，但是否重述画面取决于模型。

## 先决定是否需要生成

只需要停留、字幕、配音或二维推拉时，可以剪辑静帧。水、云、衣物或主体需要真实变化时，再考虑生成视频。静帧推拉不能提供真实三维视差或新的观察角度。

## 可填模板

```text
以实际提供的图片作为【该模型支持的参考方式】。
镜头【固定／一个主要运动及其速度】，这一段中【主要可见变化】发生。
【必要的环境微动】与主体协调，结束时【明确状态或自然延续】。
希望保持【主体形状、主要空间关系、光线或画面风格】。
```

按实际模型改写为自然描述。固定机位只表达意图，不保证完全无漂移；不能把“禁止变形”当成可靠保证。首尾帧、多参考、负面提示、时长及声音仅在模型支持时设置。

## 模型适配备注

- Runway 当前 Gen-4.5 官方指南重点描述主体、场景与镜头运动；新增或改变画面时允许补充视觉描述。
- Wan2.2 官方 I2V 示例保留较完整的外观与场景描述，不能机械套用另一模型的精简习惯。
- LibTV 中先核对具体模型和模式。平台相同不等于模型写法相同。

检查实际运动、变形、漂移、可剪用范围和前后协调。采用部分记时间范围；连续失败时简化任务、改参考或改处理方式，不无限重抽。
