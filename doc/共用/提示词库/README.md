## 共用与专属的关系

共用模板说明要说清什么；项目配方加入本项目的意境、风格与默认选择；具体镜头填入主体、实际参考与运动。例：共用“意境生图 v0.1” → 古诗词“寒江孤舟候选配方” → 某期某镜的完整提交文本。

每条项目配方写明模板版本、项目改动、适用模型、结果与采用决定。共用库更新不自动覆盖项目已采用版本；每次生成保存当时完整输入，不能只留下“使用最新版”的指针。

## 状态与边界

| 状态 | 含义 |
| --- | --- |
| 待试 | 可以先写好或从公开方法整理；尚无本项目结果支持 |
| 项目内采用 | 已在明确镜头中采用，附用户决定和实际结果 |
| 可复用配方 | 已有迁移使用记录，适用范围清楚，并获用户采用；仍非效果保证 |

创作意图尽量不绑模型，模型专用的写法及可用字段另记备注。参考数量、参数、画幅或运动改变后需要重新观察，不能承诺永久有效。

第一阶段稳定的建议信号：用户采用过完整短片；同一流程用于另一个意境仍成立；素材与输入能找回；风格、运动和音画节奏无影响表达的明显问题；尝试与消耗在约定范围内。当前尚未达到这些条件，不虚构成功率或省钱比例。
