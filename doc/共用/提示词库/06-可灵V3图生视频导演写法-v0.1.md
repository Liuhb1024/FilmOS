# 可灵V3图生视频导演写法 v0.1

2026-10-08，待本片视频实测。适用：已有采用静帧、以单图首帧生成一个连续镜头。方向已获用户授权；方法不是保证成功的配方，不自动改写其他项目或已采用输入。

## 写作顺序

1. 先看实际图片，写清主体已经处于什么姿态，什么事已经发生。不让已坐下的人重新坐、不让浮叶重新落水。
2. 用一句话确定镜头作用。心境转成可见的小动作与停顿，生平背景留在导演说明，不要求模型表演一整段传记。
3. 一个主要动作、一个主要摄影机决定。固定、轻横移、跟随后停、轻摇或后拉都可以；运动选择要解释观看关系。
4. 指明动作如何结束。鸟飞远、手放低、涟漪减弱或人安坐；动作完成后的时间也属于镜头。
5. 保持首帧构图、人物、材料、光向与景深。摄影配置卡记录设计参照，平台提交段落用可见效果表达，不把机身、f值、ISO等当已执行参数。
6. 只列本镜易坏的少数关系，如水动石不动、鸟不增殖、手花接触、月轮不变形。禁止词不能替代合理的运动设计。
7. 跨空间、跨诗境或中间过程交给剪辑。首尾帧与自动多镜头是另一个方案，不默认将相邻静帧硬接成变形转场。
8. 改词时给完整新版本，记录实际提交和出片。失败先减少同镜任务或运镜幅度，不无限重试。

```text
从实际首帧自然延续的单一连续镜头。
【主体已有状态】继续【一个主要变化】，到【自然结束状态】。
摄影机【固定或一个主要运动、方向与速度】，结尾【保持什么构图】。
【必要的环境微动】；焦点与光线保持【具体关系】。
保持首帧【最关键的主体、空间与材质】，避免【本镜特定失败】。
```

实际调用前必须将模板填成一段完整输入。时长、像素、模式、音频开关在平台设置与记录中另存；未核验的独立控件不能编造。当前官方资料说明V3时长3–15秒，后续升级包含原生4K；账号可用项与费用要看当次页面，不沿用发布初期的分辨率上限。
