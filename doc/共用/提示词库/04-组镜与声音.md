# 组镜与声音策划模板

版本 v0.1，状态待试。用于请求 Codex 规划短片，不是让单个视频模型一次生成整片的指令。

```text
把【主题／诗句／意境】组织成【目标时长与画幅】的短片方案。
观众先感到【开场】，然后注意到【变化】，最后留下【结束感受】。
已有图片／视频是【实际文件】，本期的风格约定为【已决定的内容】。
逐镜说明：用哪张图、表达什么、适合静帧剪辑还是生成运动、预期时长、怎样与下一镜衔接。
安排【旁白／朗读／环境音／音乐／静默】的进入与退出，列出待补素材。
未确定的信息标为待定，不假装已经生成、观看或听过素材。
```

先确定本期画幅、媒介、主要光色关系、运动幅度和声音方向，不为三个项目指定同一种国风。镜头可以随情绪变化，但应有理由。

意境蒙太奇可以跨空间连接，不要求每张图出现同一个人。同一地点或连续动作才检查对应空间关系；避免无意间换天气、光线和画风造成拼错素材的感觉。

旁白先试读再分配镜头时长，字幕后期统一。改配音或音乐优先调整时间线，只有画面动作与声音必须绑定时再考虑重生成。人物专属音色与对白口型不是一、二项目默认需求。

复盘保留最终顺序、采用片段范围、旁白字幕版本和声音来源。评价整段是否表达意境，不能以每张图都好看代替成片成立。[来源及项目推论](../../research/意境短片开源方法与共用库-2026-10-08.md)。
