# 宋式审美与摄影语言 · 共用资产 v0.1

2026-10-08。用户确定的建设方向：把宋式美学、精细画面与不同摄影机、镜头、光圈等摄影语言结合，沉淀为共用资产。本文仅固定组织框架，具体视觉案例、参数组合与模型配方仍待研究和实测；本轮不生成图片。

## 内容与审美

先核对诗句全文、作者处境与本镜表达，再确定可见事物。生平背景帮助理解心境，不把整篇传记或全诗意象都画进一帧；争议写年与创作性解释分别标记。

以宋式美学作为审美方向，逐镜落实到形态比例、疏密留白、虚实层次、光色关系和材料质感。具体历史样式须有来源再采用，不能把任何园林、青瓷或灰色滤镜自动称为宋式。审美方向不要求晋唐作者、服饰和场景一律改成宋代。

精细体现在准确的结构、动作、光源与材质关系，以及主次分明的细节。避免用全图硬锐化、纹理堆积或全图模糊替代精细。颜色服从诗境，不能把所有题材固定成灰雾、泛黄或橙色夕阳。

## 摄影配置卡

每镜应明确以下项目；未选择写“待定”，模型不支持或未返回写“不可控／未知”。参数用于解释预期画面，真实执行值另记。

| 项目 | 需要记录的选择与可见结果 |
| --- | --- |
| 摄影机与成像 | 机身／传感器或所参照的成像特征；选择理由，避免堆多个品牌 |
| 镜头 | 焦段及等效口径、定焦／变焦、球面／变形等选择；视野与空间表现 |
| 机位与取景 | 景别、机位高度、俯仰、距离、人物比例、前中后景和遮挡 |
| 光圈与焦点 | f值、主体距离、焦点位置、景深范围、前后景哪些结构要可读；视频是否移焦 |
| 曝光与运动表现 | 快门时间或快门角、帧率、ISO及噪点目标；静图与视频分别记录 |
| 光与色 | 时段、光源方向、软硬、明暗关系、白平衡、色彩；有无滤镜及其用途 |
| 镜头运动 | 固定、推拉、摇移等选择及幅度；服务什么表达，与主体动作如何配合 |
| 输出 | 画幅、目标像素、格式、质量档；实际返回规格与目标分列 |

摄影卡必须同时写出预期可见效果。光圈、焦段等数值不能代替“人物清楚，远山仍保留三层轮廓”这类画面要求；每镜按表达选择，不默认全片同一焦段或极浅景深。
