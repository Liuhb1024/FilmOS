## 目录和归属

```text
FilmOS/
├─ AGENTS.md                 本项目规则，配合全局规则使用
├─ .gitignore                凭据与媒体排除规则
├─ app/                      Python本地服务与原生前端
├─ tests/                    本地自动测试
├─ scripts/                  古典文本导入与摘句生成
└─ doc/
   ├─ 项目/
   │  ├─ 01-古诗词意境/
   │  │  ├─ 选题库/         诗词、出处、意境与意象
   │  │  ├─ 资产库/         本项目的素材卡及实际媒体
   │  │  ├─ 提示词库/       本项目专属配方
   │  │  ├─ 分期/           每期策划、镜头与生成记录
   │  │  └─ 协作记录.md
   │  ├─ 02-中式巨物美学/   参考库、资产库、提示词库、分期、协作记录
   │  └─ 03-王者诸韵记/     官方资料、小说、资产库、协作记录，暂存
   ├─ 共用/
   │  ├─ 提示词库/          先服务一、二项目的四类待试模板
   │  ├─ 资产库/            只放确实共用的素材
   │  ├─ 模板/              策划、镜头、素材和生成记录表单
   │  └─ 协作与归档.md
   ├─ research/             来源与方案比较
   ├─ 看板/                使用说明与实现记录
   └─ 维护/                文件清单与同步说明
```

每个项目拥有自己的内容和媒体。项目通过共用模板的明确版本形成专属配方，再产生某次完整输入；共用模板更新不自动覆盖已采用项目。人物三视图、对白口型、长篇剧情状态不是当前第一、二项目的默认前置。
