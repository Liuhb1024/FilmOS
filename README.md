# FilmOS

**把古诗的意境，做成可以持续创作的影像。**

FilmOS 是一个本地优先的 AIGC 短片创作工作区：用诗词资料库选句，以脚本组织表达，在逐镜试作中积累图片、视频、声音和可复用的提示词。Python 标准库看板负责浏览和制作记录，Codex 与创作者协作完成研究、写稿和审阅。

## 已有能力

- **诗词检索**：21,615 条来源记录，含小学、初中、高中及课外古典文本；135,918 个连续摘句片段，可按主题、意境和共鸣方向筛选。
- **跨作品组期**：选择一两句原文，保留出处与上下文，组织为一期作品；一段诗可对应多个镜头。
- **制作留档**：记录完整提示词、版本、参考素材、输出、审阅和采用决定；图片、视频与声音各有明确状态。
- **本地看板**：分类提案、摘句建期、素材导入、版本采用、归档及交付导出；数据保存在本地文件。
- **协作方法**：共用模板 → 项目审美 → 单镜完整输入 → 实际结果与反馈，经过验证再提炼可复用方法。

分类大部分来自规则初分，不代表全库精读或教材全量覆盖。看板不直连生图、视频或配音模型，也不会自动产生模型费用。

## 快速开始

需要 Git、Git LFS 和 Python。当前使用 Python 3.13 验证；看板无需安装第三方 Python 包。Node.js 仅用于前端语法检查。

```bash
# 首次使用 Git LFS 时初始化；未安装请先参阅下方官方指南
git lfs install
git clone https://github.com/Liuhb1024/FilmOS.git
cd FilmOS
git lfs pull

# 启动本地看板
python3 -m app.server
```

浏览器打开 **http://127.0.0.1:8765**。端口占用时运行 `python3 -m app.server --port 8767`。仅用于本机个人协作，不作为公网服务部署。

安装 LFS 参阅 [GitHub 官方指南](https://docs.github.com/en/repositories/working-with-files/managing-large-files/installing-git-large-file-storage)。请用 `git clone` 和 `git lfs pull` 获取媒体，避免把 LFS 指针误当成实际图片或音频。详细操作见[看板使用说明](doc/看板/使用说明.md)。

## 创作流程

1. **选句与立意**：核对作者、原文和语境，明确短片要表达什么。
2. **脚本与分镜**：排列段落、镜头、动作和节奏，确定横屏构图及组图关系。
3. **图片试作**：生成、看图、调整；完整保存输入，用户决定采用。
4. **图生视频**：基于实际图片写导演提示词，由创作者提交模型，再审阅运动结果。
5. **声音与交付**：选择音色、生成配音，按镜头整理素材，交给剪辑师。
6. **方法沉淀**：有效方案注明适用条件；失败版本清理后保留必要原因与记录。
